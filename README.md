# Football Tracking & Analysis System

AI-powered football tracking and analysis system built using computer vision and machine learning.

## Features

* Player Detection
* Player Tracking
* Speed Estimation
* Distance Calculation
* Team Detection

## Tech Stack

* Python
* OpenCV
* YOLOv8
* ByteTrack
* Scikit-Learn
